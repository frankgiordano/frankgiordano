# 2023 Linux Foundation / Open Mainframe Project Mentorship

## Unix System Services for Zowe Client Java SDK

During the Summer of 2023, I served as mentor for the **Linux Foundation / Open Mainframe Project Summer Mentorship Program** project:

**Unix System Services for Zowe Client Java SDK**

The goal of the mentorship was to expand the open-source
[Zowe Client Java SDK](https://github.com/zowe/zowe-client-java-sdk)
by completing its support for **z/OS Unix System Services (USS) REST APIs**.

I mentored **James Kostrewski**, a Computer Science student at Farmingdale State College, throughout the project.

James worked directly within the production Zowe Client Java SDK codebase to design, implement, document, and test Java APIs that allow developers to interact with Unix System Services on z/OS.

### Project Work

The mentorship focused on completing the SDK's USS REST API wrapper functionality and included experience with:

- Java API design and implementation
- z/OSMF Unix System Services REST APIs
- Working with USS files and directories on z/OS
- SDK architecture and established design patterns
- JUnit automated testing
- Mockito-based unit testing
- JavaDoc and developer documentation
- IBM z/OS and z/OSMF documentation
- GitHub-based open-source development
- Code review and iterative development
- Direct testing against mainframe environments

The work was developed with the goal of becoming part of a new public release of the **Zowe Client Java SDK**, rather than existing as a standalone mentorship exercise.

## Mentorship Outcome

A major goal of the project was to give a developer hands-on experience contributing to a real production open-source project while simultaneously expanding the capabilities of the Zowe Java ecosystem.

Through the mentorship, James moved from learning the architecture of the SDK and z/OSMF APIs to contributing production-quality Java functionality for Unix System Services.

The resulting USS support enables Java applications and automation to interact programmatically with z/OS Unix System Services through the Zowe Client Java SDK.

The project provided practical experience with:

`Java` · `z/OS` · `USS` · `z/OSMF` · `REST APIs` · `JUnit` · `Mockito` · `GitHub` · `Open Source` · `Mainframe Development`

I was very pleased to see the project result in both meaningful contributions to the Zowe Client Java SDK and valuable real-world open-source development experience for the mentee.
