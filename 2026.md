# 2026 Linux Foundation / Open Mainframe Project Mentorship

## Workflow APIs for Zowe Client Java SDK

During the Summer of 2026, I served as the mentor and project lead for the **Linux Foundation LFX Mentorship Program** project:

**[Workflow APIs for Zowe Client Java SDK](https://mentorship.lfx.linuxfoundation.org/project/c1bbdaa9-8a73-4cdf-bb82-5a5db05a2f8c)**

The project was sponsored through the **Linux Foundation** and the **Open Mainframe Project**, with the goal of expanding the open-source [Zowe Client Java SDK](https://github.com/zowe/zowe-client-java-sdk) and increasing its coverage of IBM z/OSMF REST APIs.

I had the opportunity to mentor five developers throughout the summer:

- **Jorge Samaniego**
- **Adithe Das**
- **Ashish Kumar Dash**
- **Muhammad Imran**
- **Eshaan Gupta**

The primary focus of the mentorship was implementing additional **z/OSMF Workflow and System Variable APIs** for the Java SDK. The mentees worked directly within the production Zowe codebase, following the project's established architecture, testing standards, API design patterns, documentation practices, and GitHub review process.

Their work included new APIs for areas such as:

- Creating and starting workflows
- Retrieving workflow definitions and properties
- Listing workflows and archived workflows
- Archiving, canceling, and deleting workflow instances
- Working with local workflow files
- Retrieving and managing z/OS system variables
- Expanding automated test coverage
- Fixing existing SDK defects discovered during development and integration testing
- Improving documentation and internal SDK implementation

A major part of the mentorship was learning how to contribute to an established open-source project rather than simply implementing isolated features. Contributions went through iterative design discussions, code reviews, unit testing, live z/OSMF testing, refactoring, and integration with the existing SDK architecture.

## Zowe Client Java SDK 7.0.0

The mentorship work became part of the **Zowe Client Java SDK 7.0.0** release.

Version 7 represented a significant update to the SDK and included the new Workflow and System Variable functionality developed during the mentorship, along with additional features, architectural improvements, bug fixes, modernization work, and internal enhancements.

The result was a broader and more capable Java SDK for developers building applications and automation around IBM z/OS and z/OSMF.

## Mentorship Outcome

What made this project especially rewarding was that the mentorship work did not remain experimental or isolated.

The mentees contributed directly to the official **Zowe Client Java SDK**, participated in real GitHub development and review workflows, tested against actual z/OS environments, and delivered functionality that became part of a production SDK release.

The program provided an opportunity to introduce new developers to:

`Java` · `z/OS` · `z/OSMF` · `REST APIs` · `GitHub` · `JUnit` · `Mockito` · `Jackson` · `Open Source` · `Mainframe Development`

while simultaneously advancing the capabilities of the Zowe Java ecosystem.

I am proud of what the five mentees accomplished during the program and grateful to the **Linux Foundation**, **Open Mainframe Project**, and **Zowe community** for providing the opportunity to mentor the next generation of open-source mainframe developers.
